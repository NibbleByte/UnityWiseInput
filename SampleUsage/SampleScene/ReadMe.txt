
====== Wise Input Sample Usage ======
This folder contains a sample scene that demonstrates how to use the Wise Input system in your Unity project.
The sample scene includes various input configurations and examples of how to handle user input effectively.
Please research each screen carefully as it contains valueable examples.

The scene uses shared assets from the package folder to make it easier to use and not clutter your project,
as you may want to keep this scene around for quick reference. You may also use the assets for quick prototyping,
but it is advisable to make your own customized version.
